# AdsDashboard — لوحة الإعلانات

ملف واحد: **AdsDashboard.html** — افتحه بدبل كليك في Chrome. مش محتاج نت ولا تسطيب.

- **إضافة نتيجة**: سطر لكل إعلان في كل تشيك-إن. لو كتبت اسم إعلان موجود، بيملا الريل والهدف والجمهور لوحده.
- **استيراد CSV**: من Meta Ads Manager أو TikTok Ads Manager (Export ← CSV). الأعمدة بتتربط لوحدها، وتقدر تغيّرها قبل الاستيراد.
- **الحسابات**: تكلفة المتابع، تكلفة زيارة البروفايل، تكلفة 1000 مشاهدة، معدل المتابعة (متابعين ÷ زيارات)، معدل الحفظ+الشير (÷ المشاهدات).
- **التشيك-إنات**: الافتراضي إن الأرقام «إجمالي الإعلان لحد يومها» (زي Ads Manager) — فبناخد آخر تشيك-إن لكل إعلان. لو بتدخل نتايج كل فترة لوحدها غيّرها من «إضافة نتيجة».
- **الحفظ**: كل حاجة بتتحفظ في Chrome على الجهاز ده. اعمل **Export JSON** كل فترة كباك أب، و**Import JSON** على أي جهاز تاني.

> البيانات مربوطة بالمتصفح والملف: لو فتحت الملف من مكان تاني أو متصفح تاني هتلاقيه فاضي — استخدم Import JSON.

تعديل الكود: `src/dashboard.html` وبعدين `python3 build.py` (بيحط فونت Cairo جوه الملف). الاختبار: `node test/test.mjs`.
الفونت Cairo تحت رخصة SIL OFL (`fonts/OFL-Cairo.txt`).
